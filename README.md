# Race Track

Fitness walking/running tracker UI foundation.

## Current scope
- Dark-first fitness design
- Splash/onboarding flow
- Home dashboard
- Step progress ring
- Calories, distance, active time and water cards
- Weekly activity chart
- Live activity screen UI
- Analytics/history UI
- Community/leaderboard UI
- Profile/settings UI

## Next implementation phases
1. Build and validate UI
2. Add real step sensor tracking
3. Add GPS route/map tracking
4. Calculate pace, speed, distance and calorie estimates
5. Persist workout history
6. Add Health Connect integration
7. Add challenges/leaderboards
